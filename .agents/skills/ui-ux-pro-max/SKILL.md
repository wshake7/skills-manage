# UI/UX Pro Max

When tasked with any UI/UX design or development requests, use the UI/UX Pro Max design intelligence system. This skill provides a comprehensive suite of design assets, guidelines, and reasoning rules to ensure professional, consistent outcomes.

## Activation
Activate this skill upon any request related to:
- Creating, improving, or redesigning user interfaces
- Choosing colors, fonts, iconography, or styling
- Evaluating or applying UX principles
- Building dashboards, landing pages, forms, or any UI component
- Designing charts or data visualizations
- Responding to prompts like "Build a landing page for a SaaS product"

## Design Resources
The skill includes the following resources (found in the `.ui-ux-pro-max/` directory after installation):

- **UI Styles**: 67 curated design styles (e.g., Glassmorphism, Neumorphism, Brutalism, Minimalism, etc.) with descriptions and examples.
- **Color Palettes**: 161 professionally crafted palettes with hex codes and moods.
- **Font Pairings**: 57 combinations of web-safe and modern fonts with usage guidelines.
- **UX Guidelines**: 99 actionable rules covering accessibility, hierarchy, navigation, content, and interaction design.
- **Chart Types**: 25 chart variations with recommendations for data representation.
- **Reasoning Rules**: 161 design reasoning rules to justify and critique design decisions.

## Workflow
1. **Understand the context**: Determine the project type, audience, and brand requirements.
2. **Select a UI style**: Browse the available styles and choose one (or propose a combination) that fits the mood and functionality. Justify your choice.
3. **Pick a color palette**: From the palettes, select one that aligns with the brand and emotional tone. Provide the hex codes.
4. **Choose font pairings**: Recommend heading and body font combinations from the list, explaining how they enhance readability and aesthetics.
5. **Apply UX guidelines**: Check the design against relevant guidelines to ensure usability, accessibility, and best practices.
6. **Design charts (if needed)**: For data visualization, select appropriate chart types and explain why they suit the data.
7. **Reason with design rules**: Use the reasoning rules to articulate why the design works, how it meets user needs, and how it could be improved.

## Example
```
User: Design a minimal SaaS pricing page.
AI: (activates UI/UX Pro Max)
- UI Style: Minimalism (clean, high-contrast, clear CTAs)
- Color Palette: "Soft Tech" (primary #007AFF, background #F5F5F7)
- Font Pairing: Inter for body, Space Grotesk for headings
- UX Guidelines applied: Hick’s Law (limit plans), Fitt’s Law (large buttons), Clear hierarchy
- Reasoning: Minimalism reduces cognitive load, increasing conversion. The palette conveys trust and modernity.
```

Always include the specific design asset names and references so the user can verify and adjust.
