      "content": "# Spring Boot Skill\n\n## Overview\nSpring Boot makes it easy to create stand-alone, production-grade Spring-based applications. This skill provides guidance on navigating and contributing to the Spring Boot GitHub repository (`spring-projects/spring-boot`).\n\n## Repository Structure\n- `spring-boot-project/` – Core framework modules:\n  - `spring-boot/` – Main `@EnableAutoConfiguration`, `SpringApplication`.\n  - `spring-boot-autoconfigure/` – Auto-configuration classes (e.g., DataSource, Web, Security).\n  - `spring-boot-actuator/` – Production-ready monitoring and management endpoints.\n  - `spring-boot-starters/` – POM-only artifacts bundling dependencies.\n  - `spring-boot-test/` – Testing utilities and annotations.\n  - `spring-boot-devtools/` – Developer tools (restart, LiveReload).\n  - `spring-boot-cli/` – Command-line tool.\n- `spring-boot-tests/` – Integration tests.\n- `build.gradle` / `settings.gradle` – Gradle build configuration.\n\n## Key Modules & Their Roles\n- **Auto-configuration**: Conditionally configures beans based on classpath and properties. Located in `spring-boot-project/spring-boot-autoconfigure/src/main/java/org/springframework/boot/autoconfigure/`.\n- **Actuator**: Exposes endpoints like `/health`, `/metrics`. Custom endpoints live in `spring-boot-project/spring-boot-actuator/src/main/java/org/springframework/boot/actuate/`.\n- **Starters**: One-stop dependency descriptors (e.g., `spring-boot-starter-web`). A starter’s `pom.xml` declares all needed transitive dependencies.\n- **Test**: `@SpringBootTest`, `MockMvc` helpers. Find in `spring-boot-project/spring-boot-test/src/main/java/org/springframework/boot/test/context/`.\n\n## Development Workflow\n1. **Clone & Build**:\n   ```bash\n   git clone https://github.com/spring-projects/spring-boot.git\n   cd spring-boot\n   ./gradlew build\n   ```\n\n2. **Run all tests**:\n   ```bash\n   ./gradlew test\n   ```\n   For a specific module:\n   ```bash\n   ./gradlew :spring-boot-project:spring-boot:test\n   ```\n\n3. **Run a sample application**:\n   A typical test module: `spring-boot-tests/spring-boot-smoke-tests/...`. Use `./gradlew bootRun` or execute the `main` method.\n\n4. **Check code style**: Conventions are enforced by Checkstyle. Run `./gradlew checkstyleMain checkstyleTest`.\n\n## Common Tasks\n\n### Adding a new auto-configuration class\n1. Create a class annotated with `@Configuration` and `@ConditionalOnClass`, `@ConditionalOnProperty`, etc.\n2. Register it in `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` (or `spring.factories` for older Boot versions). File location:\n   `spring-boot-project/spring-boot-autoconfigure/src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`.\n3. Add any required properties with `@ConfigurationProperties`.\n4. Write tests using `ApplicationContextRunner` (from `spring-boot-test`) to verify behavior.\n\n### Creating a new starter\n1. Create a new directory under `spring-boot-project/spring-boot-starters/` (e.g., `spring-boot-starter-foo`).\n2. Add a `build.gradle` with minimal metadata and dependencies. Reuse `io.spring.sample.starter` conventions.\n3. Do **not** include any Java source; starters are POM-only artifacts.\n\n### Modifying an Actuator endpoint\n1. Endpoints are in `spring-boot-actuator/src/main/java/org/springframework/boot/actuate/endpoint/`.\n2. Add or modify classes. Use `@Endpoint(id = "...")` for custom endpoints.\n3. Update `spring-boot-actuator-autoconfigure` if auto-configuration is needed.\n4. Test with `WebEndpointTest` or `@SpringBootTest` combined with `TestRestTemplate`.\n\n### Changing property handling\n- `ConfigurationPropertySources` and related converters are in `spring-boot-project/spring-boot/src/main/java/org/springframework/boot/context/properties/`.\n- Metadata for configuration properties is generated from `@ConfigurationProperties` using the `spring-boot-configuration-processor`. Run `./gradlew :spring-boot-project:spring-boot-tools:spring-boot-configuration-processor:compileJava` to regenerate.\n\n## Testing Guidelines\n- Unit tests use JUnit 5, Mockito, and AssertJ.\n- Auto-configuration tests heavily use `ApplicationContextRunner`.\n- For web layer, use `@WebMvcTest` or `@SpringBootTest(webEnvironment = ...)`.\n- Smoke tests under `spring-boot-tests/spring-boot-smoke-tests/` exercise real scenarios.\n\n## References\n- [Spring Boot Reference Documentation](https://docs.spring.io/spring-boot/docs/current/reference/html/)\n- [GitHub Repository](https://github.com/spring-projects/spring-boot)\n- [Contributor Guidelines](https://github.com/spring-projects/spring-boot/blob/main/CONTRIBUTING.adoc)\n"
